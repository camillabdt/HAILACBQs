# Pesquisa e avaliação experimental

Esta pasta contém protocolos que não fazem parte da execução do HAILA.

Aqui devem ficar a comparação entre pareceres de professores e modelos, os instrumentos de avaliação, scripts de análise, amostras congeladas e resultados. Um parecer de LLM é uma medida experimental; ele não aprova questões no sistema e não integra o catálogo de red flags determinísticas.

O desenho recomendado registra, para cada questão e avaliador: correção do gabarito, clareza, alinhamento ao objetivo, plausibilidade dos distratores, aderência ao formato ENADE, decisão global e justificativa. O conjunto de questões deve ser idêntico para avaliadores humanos e automáticos, com ordem controlada e versões congeladas.
